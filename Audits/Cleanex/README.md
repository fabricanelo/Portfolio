# Cleanex Argentina QA Audit

QA audit focused on identifying real production issues affecting user experience, visual consistency and business trust.

This audit was created as part of the Focus QA portfolio to demonstrate a business-oriented QA approach applied to a real website.

---

## Audit Overview

The objective of this audit was to evaluate the Cleanex Argentina website from a user and product quality perspective.

The analysis focused on:

- Visual and UI issues
- Broken or inconsistent user flows
- Usability problems
- Trust-impacting defects
- Business-impacting quality risks

---

## Testing Approach

The audit was performed using an exploratory and risk-based testing approach.

The focus was not only to detect bugs, but to understand how each issue could affect:

- user confidence
- conversion opportunities
- brand perception
- product reliability
- overall customer experience
